# Kodi Repository (Nicole / Mootjuh)

Eigen Kodi-repository voor losse addons (o.a. Red Light updates) zonder steeds de volledige Nicole-build te hoeven downloaden.

## Structuur
- `repository.batmudz/` — de repository-addon zelf
- `addons.xml` + `addons.xml.md5` — index
- `zips/` — hier komen de addon-zips

## Gebruik in Kodi
1. Download `repository.batmudz.zip` (wordt later toegevoegd)
2. In Kodi: Add-ons → Install from zip file
3. Daarna kun je addons uit deze repo installeren en updaten via Check for updates
